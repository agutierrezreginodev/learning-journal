# Aprendizaje obtenido en la etapa 00

Listo, fue un excelente comienzo esta etapa debido a que fue una introducción básica pero fundamental a como funciona el internet y como son las interacciones entre los que vemos los usuarios, la parte del cliente y como trabajan las maquinas tras bambalinas, en la parte del servidor. 

No solo la arquitectura cliente-servidor es importante, también hay que tener en cuenta como es el flujo que realiza el navegador para mostrarnos o renderizar contenido de un sitio o aplicación. Primero mediante los DNS, servidores de nombres de dominio, el navegador investiga el origen, en este caso la ip del servidor donde se encuentra alojado el codigo que renderiza el navegador y mediante el protocolo TCP/IP para la transferencia de datos mediante el internet. Una vez corroborado el origen del sitio web, en este caso la IP, el cliente envía una petición HTTP al servidor, este la procesa y envía una respuesta al cliente, la cual viene tipo json, html u otro tipo de formato de archivo, junto con un codigo de respuestas que nos permite revisar el estado de la solicitud, pueder ser un 2xx, que son codigos de exito, 3xx codigos donde nos pide tomar acciones, 4xx errores en busqueda de archivos y 5xx errores con el servidor.

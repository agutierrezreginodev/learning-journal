# Etapa 0 · Mini-proyecto: `learning-journal`

> El entregable integrador de esta etapa NO es una app: es tu **bitácora de aprendizaje versionada**, que vas a usar en todas las etapas siguientes. Es tu primer repo real con flujo profesional.

## Qué construís

Un repositorio en GitHub llamado `learning-journal` que va a acompañar todo tu plan de estudio, con estructura clara y un flujo de git profesional desde el día uno.

## Requisitos

1. **Repo en GitHub** llamado `learning-journal`, público o privado.
2. **README.md** que explique qué es el repo (tu bitácora del plan full stack).
3. **Estructura por etapas:** una carpeta por cada etapa del plan (`etapa-00/` … `etapa-09/`).
4. **Primera entrada real** en `etapa-00/` con: qué aprendiste, qué te costó, qué dudas quedaron.
5. **Mínimo 5 commits atómicos** con mensajes en inglés estilo conventional commits.
6. **Al menos 1 Pull Request mergeado** (creado desde una branch, no commiteando directo a `main`).
7. **`.gitignore`** apropiado (ej. ignorar `node_modules/`, `.env`).

## Rúbrica de aceptación (pass/fail)

| Criterio | ¿Cumple? |

| El repo existe en GitHub y es accesible | ☐ |

**Aprobado** = todos los criterios en ✅.

## Pistas si te trabás

- ¿No sabés qué poner en `.gitignore`? Buscá "gitignore node" — hay plantillas oficiales.
- ¿El push te pide credenciales? Configurá autenticación con token personal o SSH (GitHub Docs lo explica).
- ¿Commiteaste directo a `main` sin querer? No pasa nada: creá la branch para el PRÓXIMO cambio y practicá el flujo ahí.
